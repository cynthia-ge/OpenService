ADMINISTRATION · MIGRATION

Connect, review, migrate.

Bring selected records and supporting data from an authorized ServiceNow instance.

Imported accounts start disabled; imported records are private. Source passwords are never copied. Source history is preserved in an administrator-only archive. Scripts, ACL logic and external integrations require separate review and implementation.

1. Define the migration

Map destination fields to source fields. Values translate choices explicitly. Add a reviewed OpenService configuration bundle to install custom tables and workflow rules atomically. Keep credentials out of the plan.

2. Resume and review

Held only in this page's memory and sent with each fetch request. Supply it again after reopening the page.





3. Synchronize and cut over
Freeze source writes externally, run a final full synchronization, review its report and verify source completeness. Local changes or missing source records stop cutover. This records your cutover decision; it does not redirect traffic or reconfigure other systems.
